% Five authors, in the format IEEEtran documents for exactly this case.
% IEEEtran_HOWTO, "Names in Conference Mode": the \and column format is for
% "three or less affiliations"; past that, "if there are more than three
% authors and/or the text is too wide to fit across the page, use an alternate
% long format" -- names on one line carrying \IEEEauthorrefmark, then one
% affiliation block per affiliation. Five \and columns is what produced the
% lopsided 3+2 grid: IEEEtran sizes every column to the widest one, so the
% row of two sat under the row of three at the wrong pitch. This format has no

% paper is over its page limit.
