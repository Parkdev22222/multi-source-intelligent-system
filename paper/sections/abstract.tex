We study a consumer-facing satellite monitoring service that converts two
revisits of a neighbourhood into a short written change report. Such a service
must not only localise change but also avoid inventing or miscounting changed
objects. We show that this report-level factuality is determined primarily by
an upstream decision: which detections across revisits represent the same
physical object. We therefore introduce a \HeadParamsRound-parameter instance
pairing head trained from existing change masks without additional
correspondence labels. It reaches \EOnePixelFOne{} pixel F1 on LEVIR-CD and,
without retraining or threshold tuning, \ETwoPixelFOne{} on WHU-CD. More
importantly, replacing only a CLIP--geometry pairing heuristic with the learned
head improves report factuality by \EFiveGain{} CFS-F1 points and reduces
unsupported claims from \EFiveHeuristicHal\% to \EFiveLearnedHal\%, while
adding only \ESixHeadDelta~ms per tile. We evaluate report claims with a
deterministic protocol that extracts change direction and object class;
counting is assessed separately with CountMAE, and no language model is used as
judge. This evaluation reveals that a vision--language baseline shown both
images reaches only \EFourVLMChgAcc\% change-presence accuracy despite fluent
prose. In contrast, retrieval and graph aggregation over fixed instance
evidence have an observed CFS-F1 spread below \EFourLadderSpread{} points.
