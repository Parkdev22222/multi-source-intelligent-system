\section{Introduction}

We consider a consumer satellite-monitoring service in which users select an
area and receive a short written report after each new observation. Unlike
conventional change-detection systems that produce pixel-level masks for expert
analysis, this service must describe detected changes as accessible object-level
statements, such as ``four new buildings appeared on the northern edge'' or
``the lot behind the school was cleared.''

This shift changes which errors matter in ways that conventional segmentation
metrics cannot express. The deliverable is a written report that, unlike a
segmentation mask, explicitly states how many buildings appeared and whether
any change occurred at all. Two product failures follow.

\begin{enumerate}
\item \textbf{Invention.} A report announcing construction that never happened
      is worse than no report: the subscriber walks out to look, finds nothing,
      and stops trusting the service. Pixel precision cannot see this, because
      it is computed against a mask the user never sees.
\item \textbf{Miscounting.} A report may locate new construction correctly and
      still claim several buildings where one appeared. Pixel IoU stays high
      through that error, because it measures overlap rather than instance
      separation.
\end{enumerate}

\textbf{A direct vision--language baseline fails on both.} A practitioner asked to ship this
today would hand both images to a vision--language model and ask for a
description. We measure that baseline rather than dismiss it: it writes fluent,
confident prose while reaching only \EFourVLMChgAcc\% accuracy on whether the
scene changed. Its BLEU-4 of
\EFourVLMBleu{} does not expose that: the score says the wording differs from
the references, not that the content is false. Such a service would look correct in demos while remaining unreliable
in many evaluated cases.

\textbf{Our approach} generates reports from object instances detected and
matched across two images. \DetectorName~\cite{sam3} generates object-instance
proposals using open-vocabulary text prompts, and CLIP~\cite{radford2021learning}
encodes their appearance. A lightweight pairing head then matches proposals
across revisits and verifies whether unmatched instances represent genuine
changes. The resulting object-level evidence, augmented with location-based
graph context, is provided to \LLMName~\cite{exaone4} for report generation.
Consequently, building counts are derived from explicit object instances rather
than unconstrained language generation.

\textbf{Pairing is the report-level bottleneck.} Holding the report model,
prompt and graph grounding fixed, replacing only the pairing increases
Change-Fact-Score (CFS), the deterministic claim-level metric defined in
Section~\ref{ssec:cfs}, by \EFiveGain{} F1 points and lowers unsupported
claims from
\EFiveHeuristicHal\% to \EFiveLearnedHal\%. With instance evidence fixed,
structured reporting, top-$k$ retrieval, and graph aggregation achieve CFS-F1
scores of \EFourStructFOne{}, \EFourFlatRagFOne{}, and \EFourGraphRAGFOne{},
respectively, on \EFourNCrops{} crops---a maximum difference of only
\EFourLadderExactSpread{} points. The central result is therefore not that a
larger context makes the writer safer, but that better correspondence makes its
evidence reliable.

Our contributions are as follows.

\begin{itemize}
\item \textbf{Learned instance pairing.} We introduce a
      \HeadParamsRound-parameter pairing head trained from existing change
      masks without additional correspondence annotations. Using the same SAM3
      proposals, it improves pixel F1 from \EOneHeuristicFOne{} to
      \EOnePixelFOne{} on LEVIR-CD and achieves \ETwoPixelFOne{} on WHU-CD
      without retraining. Geometry alone (\EOneGeoFOne) and
      AnyChange~\cite{zheng2024segment} (\AnyChangeFOne) sit within two points
      of that rule, so the comparison is with non-learned pairing generally.
\item \textbf{Controlled detection-to-report attribution.} Holding the LLM,
      prompt, and grounding context fixed, we show that replacing only
      heuristic pairing with the learned head improves report factuality by
      \EFiveGain{} CFS-F1 points and reduces unsupported claims from
      \EFiveHeuristicHal\% to \EFiveLearnedHal\%, at an additional latency of
      only \ESixHeadDelta~ms per tile.
\item \textbf{Deterministic claim-level evaluation.} We introduce
      Change-Fact-Score (CFS), which deterministically extracts and evaluates
      claims about change direction and object class without using an LLM as
      judge; CountMAE separately measures counting accuracy.
\item \textbf{Scale-dependent grounding analysis.} We show that structured
      reporting, top-$k$ retrieval, and graph aggregation differ by at most
      \EFourLadderExactSpread{} CFS-F1 points when crop-level instance evidence
      is fixed. At the neighborhood level, however, graph aggregation reduces
      CountMAE to \ESevenGraphCountMAE, compared with \ESevenFlatCountMAE{} for
      top-$k$ retrieval and \ESevenStructCountMAE{} for full concatenation.
\end{itemize}

Our evaluation uses public benchmarks rather than a live subscriber
deployment. The consumer setting motivates the system design and metrics but
is not itself evaluated. We do not claim state-of-the-art pixel-level change
detection: benchmark-specific supervised models report 86--91 F1 on
LEVIR-CD~\cite{chen2020spatial,fang2021snunet,chen2021remote,
bandara2022transformer,codegoni2023tinycd}, whereas our focus is instance
correspondence and downstream report factuality. AnyChange~\cite{zheng2024segment}
provides zero-shot context rather than a supervision-matched comparison.
